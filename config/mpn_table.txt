# SKU -> MPN table  (client-editable, no code changes needed)

# Henry Schein order descriptions usually DON'T print the manufacturer part
# number (MPN), so the system can only anchor matching on brand/name/variant/
# pack for those items. This table supplies the MPN per Henry Schein SKU so the
# pipeline can (1) search for the exact part across suppliers and (2) reject
# listings whose part number conflicts — the single most precise match signal.
#
# Format (pipe-delimited; blank cells and lines starting with # are ignored):
#   HENRY_SCHEIN_SKU | MPN | manufacturer (optional) | note (optional)
#
# MPN is the MANUFACTURER's number (universal across resellers), e.g. Meisinger
# DCA06-170-HP-BL/O. For Henry Schein HOUSE BRANDS (Criterion, Acclean, the HS
# tray covers / cotton rolls) there is no cross-supplier MPN — the number below
# is the HS SKU itself; those still match on name/variant/pack, not MPN.
# ---------------------------------------------------------------------------
